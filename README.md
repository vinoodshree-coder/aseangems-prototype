# ASEANGEMS scholarship dashboard: suggested changes

A clickable prototype showing suggested improvements to the ASEANGEMS university dashboard.

**Live page:** https://vinoodshree-coder.github.io/aseangems-prototype/

## What to look at

1. **Scholarships tab.** Click **+ Add new scholarship** to open the form.
2. **Add a scholarship.** The current form is on the left, and the **Suggested replacement** column on the right has three collapsible sections:
   - Eligible nationalities
   - Field(s) of study
   - Eligibility & scholarship details
3. **Applications tab.** The third application, marked **Suggested redesign**, shows status changes with a confirmation pop-up.

Each suggestion has a red note explaining why it was changed.

## Notes

- This is a front-end prototype in one file (`index.html`). Nothing is saved or sent anywhere, and changes reset on refresh.
- All applicant details are sample data.
